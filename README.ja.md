# lassoDraw

[English](README.md) | **日本語**

投げ縄で選択範囲を描き終えた瞬間に塗りつぶして、選択を解除する Photoshop UXP プラグインです。
マウスを離すときに **Ctrl** を押していれば、代わりに範囲内を削除します。

形を描く → 塗られる。`Alt+Backspace` も `Ctrl+D` も要りません。

---

## 特徴

- **自動塗りつぶし** — 新しい選択範囲を描くたびに描画色で塗りつぶして選択解除
- **Ctrl で削除** — 投げ縄を確定する瞬間に Ctrl（macOS は Cmd）を押していれば削除
- **ブラシで境界線** — 選択範囲の輪郭を*現在のブラシ*でなぞる
  （サイズ・硬さ・ブラシ先端・散布まで、設定そのまま）
- **選択範囲だけ残すモード** — 描画せずに選択範囲を残す。ブラシが覆うはずの範囲を
  足した状態にもできる
- **ショートカットで ON/OFF** — 同梱のスクリプト経由
- **ロック対応** — Photoshop が拒否する操作は事前にスキップするので、ダイアログで止まらない

## 動作要件

- Photoshop 24.0 以降（UXP `manifestVersion` 5）
- ExtendScript が有効であること（Photoshop 2026 時点では有効）。
  修飾キーの取得と境界線の描画に使用します。詳細は[しくみ](#しくみ)を参照。
  無効な環境でも、判定方法をフォールバックに切り替えれば動作します。

> Windows で開発・動作確認しています。macOS でも動くはずですが未検証です。

## インストール

### パッケージから

1. [Releases](../../releases) から `com.lassodraw.photoshop_PS.ccx` をダウンロード
2. ダブルクリックすると Creative Cloud デスクトップアプリがインストールします
3. Photoshop の **プラグイン > lassoDraw** から表示

### ソースから

1. [UXP Developer Tool](https://developer.adobe.com/photoshop/uxp/2022/guides/devtool/) を用意
2. `Add Plugin...` からこのリポジトリの `manifest.json` を選択
3. Photoshop を起動した状態で `Load`

## 使い方

投げ縄ツールで描くだけです。

| 操作 | 結果 |
| --- | --- |
| 投げ縄でドラッグ → 離す | 描画色で塗りつぶし → 選択解除 |
| 投げ縄でドラッグ → **Ctrl を押しながら**離す | 範囲内を削除 → 選択解除 |

「削除」は `編集 > 消去` 相当です。通常レイヤーでは透明になり、ロックされた背景レイヤーでは
背景色で塗られます。

> **Windows での注意**
> ドラッグ*開始時*に Ctrl を押していると移動ツールに切り替わります。
> ドラッグを始めてから、マウスを離す直前に Ctrl を押してください。

### パネルの設定

| 項目 | 説明 |
| --- | --- |
| **有効** | 全体の ON/OFF。パネルのフライアウトメニューからも切り替えられます。 |
| **不透明度** | 塗りつぶしの不透明度 1〜100%。色は常に描画色です。 |
| **ブラシで境界線を描く** | 選択範囲の輪郭を現在のブラシでなぞります。[詳細](#ブラシで境界線を描く) |
| **塗りつぶさずに選択範囲だけ残す** | 何も描かず選択範囲を残します。[詳細](#塗りつぶさずに選択範囲だけ残す) |
| **削除モードの判定** | 削除したいことをどう検出するか。3 方式。[詳細](#削除モードの判定) |
| **投げ縄ツールのみ** | OFF にすると長方形・楕円選択、クイック選択、自動選択でも動作します。 |
| **1 ヒストリーにまとめる** | 塗りつぶしと選択解除を 1 回の取り消しで戻せるようにします。 |

設定はプラグインのデータフォルダー内 `settings.json` に自動保存されます。

### ブラシで境界線を描く

選択範囲を作業用パスに変換し、現在のブラシで「パスの境界線を描く」を実行します。
ブラシツールに設定されている内容がそのまま反映されます。削除モードでは消しゴムを使うので、
輪郭も内側と同じ挙動になります。

境界線を描く前に選択範囲をいったん解除する必要があります。選択範囲が残っているとブラシが
それでクリップされ、線の内側半分しか描かれないためです。プラグインが自動で処理し、必要に
応じて描画後に選択範囲を作り直します。

### 塗りつぶさずに選択範囲だけ残す

何も描かず、選択範囲を残したままにします。

| 選択範囲だけ残す | 境界線を描く | 通常の投げ縄 |
| :---: | :---: | --- |
| OFF | OFF | 塗りつぶし → 選択解除 |
| OFF | ON | 塗りつぶし + 境界線 → 選択解除 |
| **ON** | OFF | 何も描かず、選択範囲を残す |
| **ON** | **ON** | 何も描かず、選択範囲 = **元の範囲 ∪ ブラシが覆うはずの範囲** |

最後の行は「この形＋ブラシぶんの余白を選択したい」という用途に使えます。

### 削除モードの判定

| 方式 | しくみ |
| --- | --- |
| **キー状態を直接取得**（既定） | 実際の修飾キーの状態を読みます。Ctrl / Alt / Shift から選択可。 |
| **選択の合成方法で判定** | Photoshop は Shift・Alt 付きの投げ縄を別イベント（`addTo` / `subtractFrom`）として通知します。それを修飾キー代わりに使います。ExtendScript 不要。 |
| **パネルで切り替え** | 修飾キーを使わず、ラジオボタンで塗り／削除を切り替えます。 |

## キーボードショートカット

UXP には独自のグローバルショートカットを登録する API がないため、Photoshop 側の
「スクリプトにショートカットを割り当てる」しくみを間借りしています。

1. `scripts/lassoDraw Toggle.jsx` を Photoshop の Scripts フォルダーへコピー
   - Windows: `C:\Program Files\Adobe\Adobe Photoshop <年>\Presets\Scripts\`
   - macOS: `/Applications/Adobe Photoshop <年>/Presets/Scripts/`
2. Photoshop を再起動。**ファイル > スクリプト > lassoDraw Toggle** が現れます
3. **編集 > キーボードショートカット** → *アプリケーションメニュー* →
   **ファイル > スクリプト > lassoDraw Toggle** にキーを割り当て

スクリプト自体は何もしません。Photoshop はスクリプトの実行を
`AdobeScriptAutomation Scripts` アクションイベントとしてブロードキャストし、
そこに `javaScriptName` が入ります。パネルはこの名前を監視して有効／無効を反転します。
ポーリングなしのイベント駆動です。

## しくみ

このプラグインに必要な機能のいくつかは UXP の API では実現できません。
その回避策こそがこのリポジトリの読みどころです。

### 選択範囲の確定を検出する

`action.addNotificationListener(["set", "addTo", "subtractFrom"], …)` で選択チャンネルを
監視します。`to` が `{_enum: "ordinal"}` の通知（選択解除・すべてを選択）は無視するので、
プラグイン自身が発行する選択解除でループすることもありません。

### 修飾キーを読む

UXP はグローバルなキー状態を公開していません。`photoshop.core` にキーボード関連 API はなく、
ScriptUI の `keyboardState` に相当するものもありません。使えるのはパネル内 UI の
`event.ctrlKey` だけで、キャンバスにフォーカスがある間は役に立ちません。

ExtendScript には存在します。実行時に `.jsx` を生成し、`batchPlay` 経由で走らせて結果を
ファイルから読み戻しています。

```
UXP ── batchPlay { _obj: "AdobeScriptAutomation Scripts", javascript: { _kind: "local", _path: token } }
     └── ExtendScript ── ScriptUI.environment.keyboardState
                      └── "ctrl,shift,alt,meta\n<時刻>" を書き出し
UXP ── 同じファイルを読む
```

時刻を見て古い内容を掴むのを防いでいます。5 秒以上古ければ取得失敗とみなし、削除ではなく
塗りつぶしにフォールバックします（キーの取りこぼしでピクセルを消してしまわないため）。
ExtendScript エンジンは初回起動が遅いので、パネル読み込み時に一度空打ちして温めます。

### 境界線を描く

`batchPlay` の `{_obj: "stroke"}` は `executeAsModal` のスコープ内から拒否され、
`{_obj: "error", message: "", result: -128}`（＝ユーザーがキャンセル）が返ります。
ツール ID を `paintbrushTool` / `brushTool` / `pencilTool` と変えても同じで、コマンド自体が
弾かれています。ExtendScript の `PathItem.strokePath()` にはこの制約がないため、
境界線も同じブリッジを通します。この機能に `batchPlay` のフォールバックはありません。

### ブラシが覆う範囲を測る

ブラシのフットプリントを問い合わせる API はありません。ぼけ足・散布・先端形状は
ラスタライズして初めて確定するためです。そこで**使い捨てレイヤー**に描いて、その不透明部分を
選択範囲として読み取り、作業用パスと合成してからレイヤーごと破棄しています。
元の絵には何も書き込まれません。

一時レイヤーは `doc.artLayers.add()` ではなく ActionManager（`Mk` / `Lyr`）で作ります。
前者はドキュメント最上位に挿入されるため、対象レイヤーがグループ内にあると
別のレイヤーを触ってしまうからです。

### ダイアログで止まらないようにする

原因は 2 つあり、どちらも対処済みです。

- `_options.dialogOptions` に `"dontDisplay"` を使っていました。Adobe のドキュメントによれば
  これは「エラー時や追加パラメータが必要な場合は UI を表示することがある」というもので、
  透明ピクセルをロックしたレイヤーでは塗りつぶしコマンドが `preserveTransparency` を求めて
  ダイアログを出していました。現在は全コマンドで `"silent"`（UI を出さずスクリプトエラーを
  返す）を使い、`preserveTransparency` も明示的に渡しています。
- ExtendScript の `app.displayDialogs` は既定が `DialogModes.ERROR` なので、`executeAction` に
  `DialogModes.NO` を渡してもエラーはダイアログ表示されます。生成するスクリプトの冒頭で
  `DialogModes.NO` を設定し、終了時に元へ戻しています。

### ロックされたレイヤー

Photoshop が拒否する操作は事前にスキップし、理由をコンソールに出します。

| ロック | 塗りつぶし | 削除 |
| --- | --- | --- |
| すべてをロック | スキップ | スキップ |
| 画像ピクセルをロック | スキップ | スキップ |
| 透明ピクセルをロック | 実行（不透明部分のみ） | スキップ |
| 位置をロック | 実行 | 実行 |

「選択範囲だけ残す」はレイヤーを一切触らないため、どのロック状態でも動作します。

## `.ccx` を作る

```powershell
powershell -ExecutionPolicy Bypass -File package.ps1
```

`dist/<id>_PS.ccx` が生成されます。`.ccx` は `manifest.json` をルートに置いた**署名なしの
ZIP** です（UXP Developer Tool の `PluginPackageCommand` も `archiver` で zip を作るだけで、
署名処理はありません）。

ただしパッケージ前に manifest の検証があり、これを満たさないと Creative Cloud の
インストールが**エラーコード -4** で失敗します。`package.ps1` は同じ検証を行います。

- `version` が `x.y.z` 形式
- `manifestVersion` が 4 以上
- `host.minVersion` が 22 以上
- トップレベルに `icons` 配列
- panel entrypoint にも `icons` 配列

パッケージに含めるファイルは `$include` に明示列挙しています。追加したらここにも足してください。

## ファイル構成

```
manifest.json                 プラグイン定義
index.html / styles.css       パネル UI
main.js                       イベント監視と batchPlay 処理
extendscript.js               ExtendScript ブリッジ（キー状態取得 / 境界線描画）
icons/                        パネル・プラグインのアイコン
scripts/lassoDraw Toggle.jsx  ショートカット用（Photoshop の Presets/Scripts へ）
package.ps1                   .ccx を作るスクリプト
```
